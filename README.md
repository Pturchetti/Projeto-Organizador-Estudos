# Organizador de Estudos

Aplicação desktop desenvolvida em Python com Tkinter para ajudar estudantes a organizar matérias, tarefas e horários de estudo, registrar sessões e acompanhar o progresso.

## Módulos

- **`main.py`** — ponto de entrada da aplicação; reunirá a inicialização e a integração dos módulos.
- **`interface.py`** — telas, componentes visuais e navegação entre as áreas da aplicação.
- **`gerenciamento_materias.py`** — operações relacionadas às matérias cadastradas.
- **`gerenciamento_tarefas.py`** — cadastro e acompanhamento de tarefas e prazos.
- **`cronometro.py`** — temporizador para sessões de estudo, incluindo a possibilidade de usar a técnica Pomodoro.
- **`planejamento_semanal.py`** — organização e consulta do planejamento de estudos da semana.
- **`historico.py`** — registro e consulta das sessões de estudo concluídas.
- **`estatisticas.py`** — cálculo e apresentação de informações sobre o progresso e o tempo dedicado aos estudos.
- **`persistencia.py`** — leitura e gravação dos dados da aplicação em arquivos locais, como JSON.

## Pastas

- **`imagens/`** — imagens e recursos visuais utilizados pela interface.
- **`fontes/`** — arquivos de fontes que eventualmente forem utilizados.
- **`dados/`** — arquivos locais usados para persistir os dados da aplicação.

## Tecnologias

- Python
- Tkinter
- JSON para armazenamento local de dados

Os arquivos Python estão inicialmente vazios. A implementação das funcionalidades será feita pela equipe durante o desenvolvimento do projeto.
